# Aggregate reference results

These CSV files contain aggregate manuscript results only. Hourly prediction
files are excluded because they include the licensed realised EPEX target.

- `lear_qra_metrics.csv`: principal and 273-day-sensitivity LEAR-QRA metrics.
- `three_way_qw_metrics.csv`: constituent, two-model and three-model QRA metrics.
- `three_way_qw_dm.csv`: daily-loss Diebold--Mariano comparisons reported for
  the three-model QRA.

The files are verification aids, not substitutes for a lawful input snapshot.
